# StatusFlow - User Stories

## 1. Authentication & Onboarding
- **US-01**: As a new user, I want to create an account so I can manage my WhatsApp status updates.
- **US-02**: As a user, I want to connect my WhatsApp account using a 8-digit Pairing Code or QR code so I don't need to manually scan from a secondary screen if I'm on mobile.

## 2. Scheduling & Execution
- **US-03**: As a content manager, I want to upload image or video media with a caption and select a target publish time so that it posts automatically.
- **US-04**: As a business owner, I want to view a calendar of all upcoming scheduled status posts so I can plan my marketing week.
- **US-05**: As a user, I want to receive an alert if my WhatsApp session disconnects or a post fails due to network issues.

## 3. Account & Subscriptions
- **US-06**: As a subscriber, I want to upgrade my tier using Paystack so I can schedule more posts per day.
- **US-07**: As a user, I want to view my monthly post usage cap and remaining credits.
