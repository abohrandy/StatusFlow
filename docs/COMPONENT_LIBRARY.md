# Component Library Specification

- `HistoryAndCalendar`: Multi-view history and calendar module featuring Monthly, Weekly, and Daily calendar views, drag-and-drop rescheduling indicators, execution log modal, status filter pills, and caption search.
- `ScheduledQueue`: Interactive scheduled queue manager with list & calendar view modes, timezone dropdown, edit modal, cancel handler, duplicate action, and schedule validation badges.
- `StatusComposer`: Interactive editor component enabling creation of Text, Image, and Video WhatsApp statuses with real-time smartphone preview.
- `MediaLibrary`: Upload & asset manager supporting preview modals, rename, search, and delete actions.
- `DashboardOverview`: Primary analytics dashboard container displaying status, storage, subscription, and recent activity feeds.
- `WhatsAppPairing`: Dual-mode QR code and 8-digit pairing code modal.
