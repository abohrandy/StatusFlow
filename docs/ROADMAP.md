# StatusFlow - Product Roadmap

## Phase 1: Core Platform Foundation (Current)
- Complete monorepo setup & database architecture.
- Core Baileys session management & pairing engine.
- Web Dashboard MVP for scheduling image/video statuses.
- Paystack subscription engine (Starter, Pro, Agency tiers).

## Phase 2: Advanced Scheduling & Media Enhancements
- Bulk CSV/JSON status uploading & queue calendar view.
- Advanced image/video editor & overlay tool in dashboard.
- Contact group tagging & targeted status distribution.

## Phase 3: Mobile Experience (Android Native App)
- Release native Android companion app sharing backend APIs.
- Push notifications for job execution status and session disconnects.
- On-device media picker and quick-schedule widgets.

## Phase 4: Analytics & Enterprise Features
- Granular viewer analytics & status response management.
- Multi-team workspaces with role-based permissions (RBAC).
- Webhook integrations (Zapier, Make, custom REST hooks).
