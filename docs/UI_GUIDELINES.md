# StatusFlow - UI Guidelines & Aesthetic Direction

## Dashboard Layout Patterns
- **Responsive Layout**: Sidebar desktop drawer automatically converts into top bar / collapsible nav for smaller screens.
- **Glassmorphism Backdrop**: Subtitle cards and header application bars use `backdrop-blur-md` overlay effects.
- **Color Codes**:
  - Primary Accent: Emerald (`#25D366`, `bg-emerald-500`)
  - Background Base: Zinc 950 (`#09090b`)
  - Card Surfaces: Zinc 900 (`#18181b`)
- **Empty States**: Border dashed cards (`border-dashed border-zinc-800`) with clear action CTA buttons.
- **Loading Skeleton**: Shimmer effect loading cards (`animate-pulse`) while data is retrieved.
